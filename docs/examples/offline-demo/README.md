# Fictional assessment example

**SYNTHETIC TRAINING DATA — NOT LIVE INTELLIGENCE**

These complete exports were generated by the existing `osint-recon --demo`
command. They contain only the application's built-in fictional fixtures:
`internship-lab.example`, documentation IP `192.0.2.10`, three synthetic source
records and two training review items. **Zero live sources were observed.**
No provider, target, DNS service or API account supplied this evidence. No client
record, personal contact, credential or legal authorization is represented.

| File | Purpose |
| --- | --- |
| [assessment.html](assessment.html) | Self-contained, offline human review and A4 printing; expand technical disclosures before printing if needed |
| [assessment.json](assessment.json) | Complete normalized training assessment, provenance and source-linked findings |
| [assessment.csv](assessment.csv) | Three source rows; selected observations and findings are JSON-encoded cells |

The fixed source/fixture timestamp is `2025-01-15T10:00:00+00:00`. Provider-style
registration, update and analysis dates are also invented. `generated_at` is the
actual export-preparation time; it does not make any fixture current. Even the
example expiration date is historical relative to generation and must not be
treated as a live finding.

## Reproduce safely

Install and activate the project as described in the [README](../../../README.md).
From the repository root, use a **new** output directory:

```sh
osint-recon --demo --output reports/student-example-001
```

On Windows, `.venv\Scripts\osint-recon.exe` can be used without activating the
environment. Demo requires no target, key or source connectivity after
installation. Do not add a target or live authorization/source/license flags.
Subsequent exports retain the same training evidence but have a new preparation
timestamp. Existing files are protected against overwrite.

The checked-in assessment was created on 21 November 2026 from the unchanged
demo builder and exporter at baseline `5d22f8f`. Its integrity tests compare the
JSON to that builder and regenerate all three exports for byte-level agreement.
The JSON is the canonical timestamp record; this README is not a live-collection
log.

## Sharing and privacy

This directory is an intentional, reviewed exception to the rule against
committing generated assessment reports. Keep classification labels intact.
Do not replace these files with an operator export, fill them with real targets,
or commit private history, reports, worksheets, logs or keys. Normal generated
artifacts belong in ignored `reports/` or another private location. Review Git's
staged diff before every push; ignore rules cannot prevent forced additions or
protect files already tracked.

Use the [student laboratory](../../teaching/student-laboratory.html),
[operations workbook](../../OSINT_OPERATIONS_WORKBOOK.md) and
[mini-audit checklist](../../MINI_AUDIT_CHECKLIST.md) for interpretation and
handling. Live-provider acceptance remains unverified.
